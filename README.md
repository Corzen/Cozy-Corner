# Cozy Corner - Coffee & Tea Shop

A cozy, multi-page static web application dedicated to premium loose-leaf teas and specialty coffee beans. Built with vanilla HTML5 and CSS3 as a front-end web development project.

##  Features

* **Multi-Page Layout:** Seamless navigation between a Home page, a curated Coffee selection, a Tea catalog, and an About Us page.
* **Custom CSS Animations:** Utilizes `@keyframes` and smooth CSS transitions for dynamic header slide-ins and interactive card scaling.
* **Responsive Interactive Elements:** Features hover effects and styled UI components for an immersive user experience.
* **Thematic Design System:** Styled with an earthy color palette to evoke a warm, café-like aesthetic.

##  Built With

* **HTML5** – Semantic markup and page structure
* **CSS3** – Advanced styling, Flexbox layout, and custom animations (`@keyframes`)
